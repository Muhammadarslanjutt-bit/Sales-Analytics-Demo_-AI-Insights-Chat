# 🚀 Sales Analytics Demo: AI Insights + Chat

A modern, responsive sales analytics and intelligence web interface built to provide fast, actionable insights for regional sales managers and field teams.

🔗 **[Live Demo](https://muhammadarslanjutt-bit.github.io/Sales-Analytics-Demo_-AI-Insights-Chat/)**

---

## ✨ Key Features

- **📊 Dynamic Sales Hierarchy Scorecard:** Tracks performance against targets across multi-tier structures (ZSM ➔ SM ➔ ASM ➔ Rep).
- **🔄 Interlinked Multi-Select Filters:** Cascading filters across Cities, Months, Reps, Towns, and Product Groups.
- **🤖 Automated AI Insights:** Detects sales drops, lapsed pharmacies, and trending product groups automatically.
- **💬 Interactive AI Chat Assistant:** Conversational AI interface allowing sales managers to query data in real time.
- **📱 Fully Responsive Design:** Optimized for both mobile field rep access and desktop management reviews.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, Vanilla JavaScript (ES6+)
- **Styling:** Tailwind CSS
- **Data Visualization:** Chart.js
- **AI Integration:** Google Gemini API (Simulated in demo mode)
- **Deployment:** GitHub Pages
